# Repository Setup Guide

## 1. Purpose

This guide explains how the **Calib-ConvXAI** repository is organized and how it should be developed going forward.

The goal of this repository is not simply to store code.  
It is to function as a **research-oriented project repository** that keeps the problem framing, system design, implementation, and results clearly connected.
